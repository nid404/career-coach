# A Better Way To Allocate Your Career Time
https://commoncog.com/a-better-way-to-allocate-career-time/

By Cedric Chin

> **Author's note (October 2023):** The author no longer endorses these ideas, noting that capital leverage typically outweighs time considerations in career decisions.

## Article Overview

Cedric Chin presents a framework for prioritizing tasks by treating time allocation as a bet allocation problem. Rather than relying on intuition or tackling easy tasks first, he advocates for a data-driven approach that emphasizes doing riskier tasks earlier to gain valuable information.

## Key Concepts

**The Problem with Intuition**

The author argues that while experienced professionals in regular environments develop good instincts, "intuition-first approaches fail when dealing with tasks outside one's circle of competence." This is especially problematic in high-uncertainty situations like entrepreneurship or research.

**Two Methods for Task Prioritization**

1. **Expected Time Saved**: Complete riskier tasks first because failure means avoiding wasted effort on dependent tasks. The method calculates how much time you'd save if a task fails early.

2. **Failure Rate Analysis**: Rank tasks using a formula (λ = log(1/p)/T) that determines the probability of failure occurring per unit time. Tasks with higher failure rates should be attempted first.

## Why This Matters

The framework works because "humans are naturally bad at reasoning about uncertainty." By using a systematic approach instead of gut feeling, decision-makers create guardrails for their judgment in ambiguous situations.
